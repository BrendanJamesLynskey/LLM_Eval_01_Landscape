# LLM_Eval_01_Landscape

Static benchmarks vs production evals, what to measure, and the eval pyramid. Covers MMLU, MMLU-Pro, GPQA, HumanEval, SWE-bench and MT-Bench; explores what benchmarks miss (drift, multi-turn, tool use, agentic behaviour); classifies eval types (reference-based, reference-free, human-graded); walks the four-layer eval pyramid from unit tests to online A/B; and gives a practical cost model and first-eval-set recipe for teams getting started.
